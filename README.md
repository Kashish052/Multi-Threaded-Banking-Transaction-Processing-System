# Multi-Threaded Banking Transaction Processing System

A Java-based banking application developed using **Java 17, Maven, JDBC, and MySQL**.

## Project Overview

This project focuses on developing a reliable banking transaction processing system that supports account management, financial transactions, and concurrent operations.

The primary objective is to maintain transaction consistency, prevent incorrect balance updates, and ensure reliable processing when multiple banking operations occur simultaneously.

## Technologies Used

- Java 17
- Maven
- MySQL
- JDBC
- JUnit 5

## Core Features

- Savings and Current Account Management
- Deposits and Withdrawals
- Account-to-Account Fund Transfers
- Transaction History and Mini Statements
- PIN-Based Authentication
- Loan Management
- Interest Calculation
- Exception Handling
- Concurrent Transaction Processing
- JDBC Database Connectivity
